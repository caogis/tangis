## 总体结论

| 口径 | 结果 |
|---|---|
| M1 P0 功能点（F-01~F-07、F-21、F-15）**按验收标准达标数** | **0 / 9** |
| 其中**已有可用骨架** | 3 项（F-02 切片转换、F-03 3DTiles 分发分支、F-04 任务管理） |
| **完全未开始** | 5 项（F-01 数据导入、F-05 3D 预览、F-06 用户权限、F-07 打包解包、F-21 测绘合规） |
| **仅文档级完成** | 1 项（F-15：定价表与许可策略写在 PRD 3.4/2.7，代码零实现） |
| M1 出口标准「OSGB 进 → 脱密质检 → 3DTiles 服务出 → Cesium 加载」 | **链路已贯通，但每一环均为骨架/占位，判定未达出口标准** |

一句话：**工程底座（队列 + 存储 + 持久化 + 分块断点续切 + 产物分发）已扎实落地，业务功能（格式解析、OGC 服务、合规、权限、前端预览）全部空白。** 当前产物是"结构合法但几何为占位三角形"的 3DTiles，能过 HTTP 与格式校验，不能过真实数据验收。

### F-04 任务管理（队列、进度、失败重试、日志下载、参数版本化）

| 项 | 内容 |
|---|---|
| 验收标准 | 任务幂等，失败可从分块断点恢复 |
| 已实现 | ✅ NATS JetStream：`queue/queue.go` Stream `TANGIS` / subjects `TASKS.*` / durable `tangis-worker` / Ack-Nak-DoubleAck / 毒消息 Term / ackWait 5min；✅ 状态机 `worker/worker.go:111-162` PENDING→RUNNING→SUCCEEDED/FAILED；✅ **幂等**：仅 PENDING 才执行（:121-123）；✅ 持久化 `task/pg.go`（pgxpool，DATABASE_URL 为空则回退内存 `store.go`）；✅ 产物自动上传 MinIO 并记 `minio_prefix`，失败降级不阻塞 |

## 四、M1 出口标准判定

| 链路环节 | 现状 | 判定 |
|---|---|---|
| OSGB 进 | 任务 API 接收路径字符串，内核不解析，直接产出占位三角形 | 🟡 入口存在，解析缺失 |
| 脱密质检 | 无任何处理 | ❌ 断裂 |
| 3DTiles 服务出 | `tileset.json` + `*.b3dm` 结构合法，HTTP 200 可拉取（本地/MinIO 双路） | 🟡 结构通，内容占位 |
| Cesium 加载 | 无前端宿主，仅 curl 级验证 | ❌ 断裂 |

**结论：骨架贯通（POST /api/v1/tasks → NATS → kernel build → SUCCEEDED → /services/{id}/tileset.json 200），但未达 M1 出口标准。**

## 五、差距排序与建议下一步

按「关键路径 + 依赖顺序」排序，前三项是打通出口标准的必要条件：

1. **真实几何解析（F-02 核心）** — 用 `testdata/osgb`（.osgb + src/*.obj）打通 OBJ→GLB→b3dm，替换 `build_b3dm()` 占位三角形；随后攻 OSGB（OpenSceneGraph 二进制）解析与 LOD 重建。**这是 M1 最大难点，应最早启动、最长排期。**
2. **任务模型补齐（F-04 → ~80%）** — 加 `progress`（分块完成数/总数）、`params`（参数版本化）、日志落盘与下载接口、失败重试策略（指数退避 + 最大次数）。成本低、收益高，可与 1 并行。
3. **F-21 最小合规子集** — 坐标系识别与转换（EPSG:4490/4326/3857 + CGCS2000 七参数，参数加密存储）、DEM 脱密（高程抽稀 + 坐标偏移）、发布审批开关（审批通过才进 `/api/v1/services`）。让出口链路「脱密」环不再为空。
4. **F-05 最小预览页** — Vue3 + Vite + Cesium 单页，加载 `/services/{task_id}/tileset.json`，验证真实 tileset 可渲染（同时暴露占位几何的渲染问题）。
5. **F-06 最小鉴权** — API Key / 服务访问 Token + 防盗链签名，`tasks` 表加 `tenant_id`。当前分发完全裸奔，建议不晚于预览页落地。
6. **F-03 2D 起步** — 先做影像 WMTS/TMS（复用 MinIO 存储 + 接入 Redis 缓存），完整 OGC 全家桶留到 M2。
