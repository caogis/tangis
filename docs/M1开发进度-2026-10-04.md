- testdata 的 4 个 `.osgb` 实为未压缩 OSG 二进制流，已可真实解析并接入 build 管线（corpus 测试逐分量对照 OBJ 通过）。

## 三、前端（web/，F-05，全新 20 文件）

Vue 3.5 + vue-router + cesium 1.146 + vite-plugin-cesium。侧栏 SPA：任务列表（非终态 5s 轮询）、新建任务表单、任务详情（进度/日志/失败面板）、Cesium 预览（服务列表 + zoomTo + 点击拾取属性/经纬高）。设计按「Terminal meets Editorial」：OKLCH 墨绿、衬线展示 + 等宽 UI、细边框、150-250ms 克制动效。API 客户端对字段命名/包装形态宽容兼容；后端不可达显示明确错误，无假数据。

启动：`cd web && npm run dev`（可选 `VITE_API_BASE` / `VITE_API_KEY`）。

## 四、集成注意事项

1. **manifest 衔接**：worker 已通过 `chunksFromSource` 为目录源生成带 `source` 的真实分块；source 非目录时回退骨架 manifest，新内核会明确报错（任务 FAILED 并带原因），不再产出占位几何。
2. **CORS 仍全开**：便于本地前后端联调，M2 收紧。
3. 默认开发密钥（`tangis-dev-key` / `tangis-dev-sign-secret`）仅限本地，生产部署必须替换并删除 initdb 播种。
