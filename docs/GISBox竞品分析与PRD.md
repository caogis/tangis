## Executive Summary

GISBox（山海鲸生态）是一款**免费+增值付费**的一站式 GIS 轻量化桌面工具，核心能力为三大板块：**GIS 场景编辑、切片转换、服务分发（内置 GIS Server）**。其竞争力在于：双击安装即客户端即服务器、OSGB/高斯泼溅/BIM 实时编辑、海量格式互转、OGC 服务全免费。

其核心短板（也是本产品的机会点）：

1. **单机架构**：切片任务只能跑在本机，无分布式/集群能力，大场景（数十 GB OSGB）处理慢且失败率高（官方 FAQ 中大量切片失败案例）。
2. **闭源黑盒**：内核不可扩展，无插件体系，API 仅企业版开放且需绑定账号。
3. **协同能力弱**：SaaS 协同为企业版付费功能（¥389/月，20 席位），且依赖其自家云端。
4. **渲染引擎依赖第三方预览框架**（Cesium/OpenLayers/Leaflet/Mapbox），场景编辑器为自研但不开放扩展。
5. **BIM/高斯泼溅等新格式为付费墙功能**，DWG 服务分发、模型轻量化均需付费。

本 PRD 定义对标产品 **「TanGIS」（暂定名）**：**开源内核 + 云原生切片集群 + 实时协同（双轨席位）+ WebGPU 渲染 + 全开放 API**，在架构、性能、开放性、协作四个维度建立代差。北极星指标：**付费团队数**。

### 1.3 竞品优劣势总结

**优势：**
- 免费 GIS Server + OGC 全家桶，切入成本低；
- OSGB 实时编辑（抠除/压平/修模）是差异化亮点，减少 Smart3D/MeshLab 二次处理；
- 格式覆盖面广（含高斯泼溅、RVT/IFC BIM，及 S3M 行标 / I3S OGC 社区标准格式）；
- 桌面安装即用，对测绘院/中小项目团队友好；具备测绘资质与信创认证，可服务军工/政企大 B 客户。

**劣势（PRD 机会点）：**
- **P1 性能**：切片单机串行，无断点续切/分布式，官方 FAQ 高频出现"切片失败/闪烁/卡死"；
- **P2 开放性**：闭源、无插件体系、API 付费且绑定账号，无法二次开发嵌入客户业务系统；
- **P3 协作**：协同编辑为高价付费墙，席位制，无开源替代；
- **P4 架构**：桌面软件形态在服务器/云上部署笨重，不容器化、不可弹性伸缩；
- **P5 渲染**：预览依赖 Cesium 等第三方，游戏级渲染仅在其自研场景编辑器内，服务端无流渲染输出能力。

## 第二部分：新产品 PRD —— TanGIS（暂定名）v1.1

### 2.1 产品定位

**开源内核、云原生、可私有化的新一代 GIS 数据处理与分发平台**：
一句话——"GISBox 能做的都能做，且切片可横向扩展、全开放 API、协同开源可用、容器化部署"。

| 维度 | 目标 |
|---|---|
| 目标用户 | ① 测绘/实景三维生产单位（测绘院，刚需：质检/坐标转换/轻量化/脱密）② 数字孪生集成商（刚需：格式转换/服务发布/开放 API）③ 政企 GIS 平台开发者（刚需：私有化/信创/合规） |
| 核心场景 | 倾斜摄影/BIM/高斯泼溅数据处理流水线；OGC/3DTiles 服务发布；多人文档级三维场景协同 |
| 交付形态 | ① 桌面/单机版（对标 GISBox 体验）② Docker/K8s 集群版 ③ 纯 SDK/API 版 ④ 企业版（资质配套 + 私有化交付 + SLA，服务大 B） |
| 开源策略 | Open Core：核心（切片引擎 + OGC Server）开源；商业功能（高级协同、License 校验的企业能力、AI 高级能力）商业授权，**License 机制 M1 即落地** |

### 2.7 合规与开源许可策略 ✱ v1.1 新增

1. **测绘合规**：互联网地图服务对外发布需测绘资质——M1 起明确两条路径（与持证单位合作 / 申请互联网地图服务资质）；DEM 脱密、七参数托管为 P0 交付项，不是可选项。
2. **GPL 隔离**：LibreDWG（GPLv3）以**独立进程 + 管道通信**方式调用，主程序不含 GPL 代码；商业客户推荐 ODA SDK 授权版。
3. **开源 License 建议**：核心 Apache-2.0（商用友好）；商标与"开源版限 3 席位"条款通过 CLA + 商标政策保护，防云厂商白嫖。

### 3.2 技术选型及「优于 GISBox」论证

| 层 | 推荐技术 | 理由（对比 GISBox） |
|---|---|---|
| 桌面壳 | **Tauri 2（Rust）**，WebGPU 成熟前渲染以 WebGL2 为主 | 安装包 ~10MB，内存占用低；与 Rust 内核同语言可复用 |
| Web 前端 | **Vue 3 + TS + Vite + TanStack Query + shadcn/vue** | 与团队既有栈一致 |
| 3D 预览 | **Cesium（3DTiles 底座）+ Three.js（深度缓冲融合）**；WebGPU 为渐进增强 | GISBox 仅"支持"第三方加载；我们自研渲染层自主可控 |
| 服务端 | **Go（Gin/Echo）业务服务**；数据面（瓦片出图/切片）按团队规模选 Rust(Axum) 或 Go+cgo | Go 迭代快；Rust 热路径零 GC；分级方案避免架构绑架（见 2.5） |
| 切片内核 | **OSGB→3DTiles 核心自研**（LOD 层级重建、父子聚合、纹理 atlas——开源库不覆盖的部分）；格式解析复用 GDAL(rust-bindings)/las/obj crate；多线程（Rayon 或 goroutine 池）+ 可选 GPU 压缩（wgpu→BasisU/KTX2）| GISBox 单机串行；我们多线程 + 可分布式 + 断点续切（分块 Manifest） |
| GIS Server | **Go 自研 OGC**（WMTS/WMS/WFS-T/WCS + OGC API - Tiles/Features/Maps）+ PostGIS 几何运算；MVT 用现成库 | 无授权风险，开源实现可审计 |
| BIM | **IfcOpenShell(Python) + IFC 主路线**；RVT 引导导出 IFC 中转 | RVT 闭源是行业事实，诚实收缩范围优于 GISBox 式承诺 |
| DWG | **DXF 优先（开源解析）**；LibreDWG 独立进程隔离 GPL；ODA SDK 作商业授权选项 | 规避 GPL 传染与法律风险 |
| 协同 | **Yjs/自研 CRDT over WebSocket**；开源版 3 席位 / 商业版不限 | GISBox 协同 ¥389/月；我们保留升级钩子同时给开源社区抓手 |
| 任务队列 | **NATS JetStream（唯一选型）** | 持久化/重放/通配主题满足 DAG 编排需求 ✱ v1.1 收敛 |
| 存储 | **PostgreSQL 16 + PostGIS 3、Redis、MinIO**；切片暂存 Worker 本地 NVMe | 全开源零授权成本；异步批量上传规避写放大 ✱ v1.1 补充 |
| 部署 | **Docker Compose（单机一键起）/ Helm Chart（集群）/ 离线安装包（信创 ARM64）** | 三种交付形态 + 企业版私有化交付 |
| 可观测 | OpenTelemetry + Prometheus + Grafana + Loki | 任务失败可归因，强于 GISBox 本地日志 |

### 3.3 关键架构决策（ADR 摘要）

1. **语言策略按团队分级**（v1.1 修订）：≥8 人维持 Go 业务面 + Rust 数据面；<5 人全 Go + cgo。边界经 gRPC/NATS，随时可拆可合。
2. **切片任务 = 分块 Manifest + 拓扑排序 + 调度亲和性**（v1.1 强化）：Worker 优先续跑同节点分块，跨分块 LOD 合并按依赖排序；产物本地 NVMe 暂存异步上传——相对 GISBox 最核心的架构代差。
3. **服务输出即标准**：3DTiles 1.1、OGC API 系列优先，旧版 WxS 兼容；打包容器格式公开规范。
4. **编辑增量写回**（收缩为试点）：OSGB 编辑按 tile 粒度增量更新，P1 试点验证后决定是否全面推广。
5. **渲染分级**（v1.1 修订）：桌面与 Web 预览 WebGL2 为主、WebGPU 渐进增强；服务端流渲染仅 GPU 节点池，无 GPU 明确降级。
6. **合规内建于架构**（v1.1 新增）：脱密/七参数托管/发布审批为 P0 服务，不可绕过。
