## 二、P0 分项详述

### F-01 数据导入 🟡 25%
- **真解析能力已在内核落地**：OSGB（`kernel/crates/osgb/parser.rs`，依据真实 osgconv 3.6.5 语料逐字段逆向，Group/Geode/LOD/PagedLOD + Geometry + DrawElements + 纹理 INLINE_DATA/EXTERNAL + zlib 解压）、OBJ（tobj，含真纹理，`cli/src/geometry.rs:137`）、GeoTIFF（自写 TIFF 解析器 `geo/tiff.rs`，支持 Strip/Tiled、Deflate、8bit/RGBA）。
- **未串成"导入"能力**：服务端无上传/多格式探测/任务派发管线（`api/handlers.go` 仅 `type/source/output` 三字段），前端 `TaskNewView.vue` type 下拉只有 `osgb2tiles` 一项，无坐标系识别 UI。
- 缺口：12 格式中仅 OSGB/OBJ/GeoTIFF 有解析器；GLTF/FBX/DEM(作为地形)/LAS/SHP/GeoJSON/GeoPackage/DXF 全无；坐标系识别（内核 `geo/crs.rs`）未接入导入流程。

### F-02 切片转换 🟡 75%（本轮最大增量）
- **OSGB→3DTiles 已从占位升级为真实**：`cli/src/tiles/b3dm.rs:3-5` 明写"占位三角形路径已删除"；真实 GLB 含 POSITION/NORMAL/u32 索引/`_BATCHID`（每 `osg::Geometry` 一 feature），POSITION min/max 按真实数据计算（`:106-108`），Z-up→Y-up 坐标管线（`:19-35`），绕序统一翻 CCW（`:53-59`，修复过 Cesium 中模型不可见的缺陷），内嵌纹理转 PNG 并写 `pbrMetallicRoughness.baseColorTexture`（`:115`）。
- **tileset 正确性**：`tiles/tileset.rs:14-32` geometricError 按真实几何尺度推导（修复"全叶子 → ge 全 0 → Cesium 永不细化"）；`--origin` 写 root ENU→ECEF 4×4 transform（`:104`），测试用 pyproj 独立黄金值比对误差 <1m（`:452-476`）。
- **影像→XYZ 瓦片真实可用**：`cli/src/raster/xyz.rs:57-161`，WebMercatorQuad 金字塔 + `metadata.json` + 无数据区透明 + Rayon 瓦片级并行（`:11,121-124`），zm 范围自动推导不超采样。
- **并行与断点续切**：`main.rs:47` rayon；`manifest/journal.rs` JSONL 增量日志把整体回写从 O(n²) 降到 O(n)，崩溃安全 + replay。
- **未完成**：地形→Terrain/Quantized-Mesh（全仓零命中）、点云 LAS、WMTS 布局（xyz.rs 只接受 xyz）；性能为**外推非实测**（见第四节）；公开基准数据集未发布。

### F-03 服务分发 🟡 60%
- **已真实实现**：WMTS 1.0.0 KVP GetCapabilities/GetTile（`service/wmts.go:33-69`）+ RESTful GetTile（`:72`），Capabilities 由真实 `metadata.json` 生成、`TileMatrixSet` 0–24、`TileMatrixSetLimits`、`ResourceURL` 齐备（`:119-236`），支持 WebMercatorQuad + WorldCRS84Quad（`tiles.go:75-101`）；TMS（Y 轴翻转 `tiles.go:281`）；**MVT**（PostGIS `ST_AsMVT` + 3857 动态投影 + GiST `&&` 过滤 + 超限 413，`vector/gateway.go:261-293`）；3DTiles 分发：本地优先 + MinIO 回源（`service/service.go:256-282`），并对 tileset 子资源做**递归签名改写**（3D Tiles 1.0/1.1 三种 content 形态，`service/tileset.go:44-156`）。
- **WFS 2.0 只读子集**：GetCapabilities（真实图层生成 `vector/wfs.go:89-121`）+ GetFeature(GeoJSON)；**缺 DescribeFeatureType、GetPropertyValue、WFS-T 事务**。
- **缺口**：WMS、WCS、Terrain(quantized-mesh)、OGC API Tiles/Features/Maps 全无。

### F-04 任务管理 ✅ 85%（唯一基本达标项）
- 队列 NATS JetStream + durable + DoubleAck；状态机 PENDING→RUNNING→SUCCEEDED/FAILED；幂等（仅 PENDING 执行，`worker.go:207`）。
- 进度 `Progress{Done,Total}` 由 manifest 分块轮询（2s，`worker.go:289-299`）；**重试**指数退避 10s/60s/300s 最多 3 次（`worker.go:51,324`）；**日志下载** `data/logs/{id}.log` + `GET /tasks/:id/logs`；**参数版本化** `params` 列；编辑任务（`worker/edit.go`）、质检任务（`worker/qc.go`）、t3d 导入三类新任务类型。
- 多租户 SQL 级隔离（`task/pg.go:134,153,213`）；配额中间件 429 + Retry-After（`api/quota.go:17`）。
- **缺口**：**任务取消/暂停全仓零命中**；Webhook 仅 1 种事件（终态），无订阅管理 API；前端无重试按钮。

### F-05 3D 预览 🟡 55%
- `web/src/views/PreviewView.vue`：Cesium3DTileset 加载 + zoomTo（146-154）、服务列表 + WMTS 影像叠加（194-196）、**属性查询** `drillPick(8)` + `getPropertyIds`（323-360）、签名过期倒计时面板。
- **缺口**：场景树、测量工具（距离/面积/高程）全无；100GB 级流式加载未做压力验证。

### F-06 用户与权限 🟡 60%
- API Key SHA-256 哈希校验（`auth/auth.go:57,191`）+ 禁用 403 + `api_keys` 自动迁移；角色 admin/tenant（`auth.go:27-30`）；每日配额 PG `api_key_usage` upsert（`auth/quota.go:75-82`）；多租户 SQL 隔离；HMAC-SHA256 防盗链签发/校验/中间件（`auth.go:217,227`、`router.go:249`），3D 分发侧强制（`service.go:220`）。
- **缺口**：**无注册/登录/密码/JWT**（全仓零命中）；无短期服务访问 Token；无 Key 增删改 REST API（仅播种 `EnsureRawKey`）；无前端用户页。

### F-07 打包解包 🟡 60%
- `.t3d` 公开 ZIP 容器（对标 GBP 但公开，规范见 `docs/CONTAINER-FORMAT.md`）：manifest.json 首条目 + `tiles/` 前缀强制（`t3d/format.go:24-35`）；流式 zip + 逐文件 SHA256（`pack.go:29-102`）；解包 Zip Slip 双重防线 + 条目集合双向对照（`extract.go:43-175`）；三种源（本地/MinIO/回源）。
- **缺口**：仅覆盖 3DTiles 产物（要求含 tileset.json），**OSGB 打包解包未实现**。

### F-21 测绘合规 🟡 55%
- **真实实现**：CRS 双路径识别（GeoTIFF GeoKey 34735 + ESRI/OGC WKT `.prj`），支持 4326/**4490 CGCS2000**/4479 CGCS2000(3D)/4610/4214/4269 + 3857 + UTM 32601–32760 + CGCS2000 高斯-克吕格 4491–4554，列表外**明确报错不猜测**（`geo/crs.rs:12,44-57`）；**七参数 Bursa-Wolf**（EPSG 9606/1033，`geo/bursa.rs:1-16`，含 Coordinate Frame 兼容、CGCS2000/WGS84/WGS72 椭球常量、官方算例）；**DEM 脱密** flatten/noise 两模式 + seed 可复现 + 保留地理 tag + 审批留痕 JSON（`geo/dem.rs:5-6,142-144`）；**发布审批流**（`api/handlers.go:331` admin 二次校验，`Approved` 为分发前置 `service.go:184`）。
- **缺口**：七参数**保密加密托管**未做（参数是明文样例 JSON）；无水印；DEM 缺高程抽稀/坐标整体偏移/等高距限制；无天地图底图 + GCJ-02 纠偏；无资质路径文档落库；合规 UI 全部没有。

### F-15 商业化基础 🟡 70%
- `LICENSE`（Apache-2.0 全文，草果软件 2026）+ `docs/LICENSE-BOUNDARY.md`（v1.0，开源/商业边界清单，质量高）；Ed25519 License 验签 + 特性开关机制（`license/license.go:141,162`）。
- **缺口**：**仅 `distributed_slicing` 一个真实门禁点**（`handlers.go:154`），collab/SSO/信创/管控台 4 项常量无调用；公钥为开发占位（`license.go:77`，注释标明生产必改）；设计伙伴未启动。
- 额外：`POST /tasks/:id/edit` 未挂配额中间件（`router.go:116`），编辑任务可绕过每日配额 —— 属于商业化闭环的漏洞。

## 三、P1 亮点与缺口

- **F-08 质检超额完成**：五项真实算法与口径文档见 `docs/qc-report-README.md`：退化三角形（零面积/重复索引/重复面）、法线翻转（共享边夹角 >120° + 孤立法线翻转率）、悬浮块（体素 26 邻域连通分量，>30m 且体积占比 <0.05）、**跨 tile 裂缝**（文件名 `+N_+M` 解析网格坐标 → 相邻配对 → 边界顶点最近距离）、自相交（空间哈希 + Möller–Trumbore + 近共面 2D 边交叉）。检测关闭时字段为 `null`，**不编造 0**。
- **F-09 编辑**：clip 用平面半空间 Sutherland–Hodgman 式切分，面积守恒 `area_in = area_kept + area_removed`；flatten 带 feather 米线性过渡；ground-align 刚性平移不缩放（避免接缝错位）。**缺 Web 端交互式刷选**、**缺 OSGB 二进制写回与 tile 级增量 patch**（只能导出 OBJ/b3dm）。
- **F-12 轻量化**：QEM(Garland–Heckbert) + **瓦片接缝保护**（边界边不折叠/边界顶点不移动，测试断言跨 tile 共享坐标逐字保留）。缺 KTX2/DRACO、缺重建顶层。
- **F-13 DXF/DWG、F-11 BIM：完全未动**（F-13 是 PRD P1 里唯一一行未起头的）。
- **F-14**：`docs/openapi.yaml` + 双向防漂移测试（`api/openapi_test.go`）质量好；Webhook HMAC + 1s/2s/4s 重试，但仅终态 1 事件、无订阅管理与投递历史。
